# Дорожные карты — настольное приложение

Python + pywebview (окно Windows на движке Edge WebView2). Интерфейс — `ui/` (чистый HTML/CSS/JS, без сборки).
Запуск: `Запустить.bat` (или `.venv\Scripts\python.exe app.py`, с `--debug` — открываются DevTools).
Сборка .exe: `build.bat` → `dist/Roadmaps/`. Пример карты для первого запуска — `examples/`.

## Как Claude делает карты

Каждая карта — один файл `roadmaps/<id>.json` (id = латиница, дефисы). Приложение раз в ~1 с проверяет папку
и само подхватывает новые/изменённые файлы — перезапуск не нужен. Чтобы создать карту, просто запиши новый файл;
чтобы изменить — прочитай файл и отредактируй его. Удалённые из приложения карты лежат в `roadmaps/.trash/`.

### Формат

```json
{
  "title": "Название карты",
  "description": "необязательно",
  "order": 1,
  "notes": [ { "text": "Подпись на холсте", "x": 0, "y": -60, "size": 20, "color": "#eab308" } ],
  "stages": [
    {
      "id": "m1",
      "title": "M1 Прототип",
      "type": "stage",
      "after": ["m0"],
      "flag": true,
      "status": "active",
      "description": "Короткое пояснение",
      "tasks": ["[x] Сделанная задача", "Несделанная задача", { "text": "так тоже можно", "done": false }],
      "tag": "метка внизу карточки",
      "color": "#8b5cf6",
      "x": 0, "y": 0, "w": 300
    }
  ]
}
```

- `type`: `"stage"` — карточка со списком задач (по умолчанию), `"milestone"` — веха-ромб (контрольная точка, обычно без задач).
- `after`: id этапов, после которых идёт этот этап → рисуются стрелки слева направо.
- `x`, `y` можно **не указывать**: приложение само разложит этапы по колонкам по зависимостям `after`
  и запишет координаты в файл. Если пользователь уже двигал карточки, координаты сохраняй как есть.
- `status` обычно не нужен — он считается по задачам (нет готовых → «не начат», часть → «в работе», все → «готов»).
- `flag: true` — жёлтый флажок «важно». `order` — порядок карты в списке слева.
- Все поля, кроме `title` у карты и `title` у этапа, необязательны.

### Советы по хорошей карте
- 5–20 этапов, в каждом 3–12 конкретных задач (действие + результат).
- Параллельные направления — разные ветки `after`; точки сбора веток — вехи (`milestone`).
- Названия этапов короткие, с номером: «M1 Greybox», «M2 Экономика».
- Пиши файл в UTF-8, JSON должен быть валидным (иначе карта в списке помечается «ошибка»).

## Файлы
- `app.py` — окно и API для JS (list_maps, load_map, save_map, create_map, delete_map, export_markdown, save_png, mtimes).
- `ui/app.js` — холст (зум колесом, перетаскивание, связи, мини-карта, таймлайн, редактор этапа, undo/redo).
- `ui/style.css` — тёмная тема.
